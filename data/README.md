# Dados

Esta pasta guarda arquivos de persistencia simples em texto.

## Arquivos

- `moedas.txt`: regista a quantidade de moedas adquiridas ao matar inimigos.
- `nivel.txt`: nível de dificuldade dos inimigos, aumentado quando um boss é derrotado.
- `upgrades.txt`: quais melhorias foram compradas pelo jogador.
- `README.txt`: arquivo legado; manter por compatibilidade se necessario.

## Observacao

Evite versionar dados pessoais reais dos jogadores.
